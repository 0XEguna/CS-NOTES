### Tokens: Type of tokens

#### Prepocessor Directions
"#" include (used for including a system file location storing
useful information)

#### Identifiers
a, b, main (should be used once in a program to mean 
the beginning of where code executes – but it is not a 
reserved/keyword)

#### Operators
+, &

#### Punctuation
{;}

#### Comments

/* ..... */ or // for inline

### Keywords/Reserved words

auto, break, case, char, const, continue, default, do, 
double, else, enum, extern, float, for, goto, if, int,
long, register, return, short, signed, sizeof, static, struct,
switch, typedef, union, unsigned, void, volatile and while
